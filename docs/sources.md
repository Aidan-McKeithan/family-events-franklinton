# Approved event sources

Checked on September 1, 2026.

## Franklin County, North Carolina

- Owner: Franklin County government
- Method: official CivicPlus iCalendar subscription feeds
- Directory: https://www.franklincountync.gov/iCalendar.aspx
- Enabled categories: Library, Kids & Teens, and Parks & Recreation
- Evidence: the directory explicitly invites users to subscribe so calendars update as events are added
- Retrieval: one polite daily request per enabled feed with a project-identifying user agent
- Limitations: venue coordinates are not included, so unmatched venues use labeled town-level approximate coordinates; missing age, cost, setting, accessibility, and registration details remain unknown

## Granville County, North Carolina

- Owner: Granville County government
- Method: official CivicPlus Library iCalendar subscription feed
- Directory: https://www.granvillecounty.org/iCalendar.aspx
- Enabled category: Library
- Evidence: the directory explicitly offers calendar subscriptions
- Retrieval: one polite daily request with a project-identifying user agent
- Limitations: only events within the supported mapped towns can be displayed; town-level coordinates are labeled approximate

## Manual supplemental sources

Franklinton Parks and Recreation, Wake Forest official event pages, and the Arts Council of Franklin County may be curated manually. They are not automatically collected until a stable permitted feed or adapter is reviewed.

The collector never bypasses access controls. A failed source retains its last known good events and is marked stale. Every displayed event links to an official source so caregivers can confirm details.
